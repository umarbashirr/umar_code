Tandem

A terminal with an agent and a browser it can drive.

Two riders, one machine, either one can steer.

Cursor puts an agent next to an editor. Tandem puts one next to a shell and a live browser.

Install

Install

Linux

curl -fsSL https://raw.githubusercontent.com/umarbashirr/umar_code/main/install.sh | sh

Windows PowerShell

irm https://raw.githubusercontent.com/umarbashirr/umar_code/main/install.ps1 | iex

Needs an existing Claude Code login. The agent uses claude.

Agent, terminal, browser
